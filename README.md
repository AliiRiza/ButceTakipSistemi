#  Bütçe Takip Sistemi (Budget Tracker)

Bu proje, kişisel gelir ve giderlerinizi takip etmenizi sağlayan, anlık bakiye hesaplaması yapan ve harcamaları kategorize eden bir web uygulamasıdır.

##  Özellikler

- **Dashboard:** Anlık toplam bakiye, günlük/haftalık/aylık gelir-gider özeti.
- **Kategori Yönetimi:** Gelir ve Gider kalemleri için özel kategoriler oluşturma.
- **İşlem Takibi:** Harcama veya gelir ekleme, düzenleme ve silme.
- **Filtreleme:** Tarih aralığına ve kelimeye göre harcama arama.
- **İstatistikler:** Harcama alışkanlıklarını analiz eden dinamik hesaplamalar.

##  Kullanılan Teknolojiler

- **Backend:** ASP.NET Core 8.0 MVC
- **Veritabanı:** Entity Framework Core (Code First)
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **IDE:** Visual Studio 2022

##  Kurulum

1. Projeyi bilgisayarınıza indirin.
2. `appsettings.json` dosyasındaki veritabanı bağlantı yolunu (Connection String) kendi sunucunuza göre ayarlayın.
3. Package Manager Console üzerinden `Update-Database` komutunu çalıştırarak veritabanını oluşturun.
4. Projeyi çalıştırın.
